# Scene 0.2.3 (alpha)

A small update to Scene 0.2.2.

**This is still an alpha.** Expect rough edges and changes between releases. Export your settings before you update, and report anything that breaks in Issues.

### Changes
- Newly popular's See all loads more titles as you scroll, until it reaches the end of the 3, 6 or 12 month window you pick. A 12 month window now holds around a thousand titles
- Picking Films, Series or Anime in See all loads only that kind, so it opens faster
